Controls

How the ledger is kept honest

  • Every rupee that moves is one row. Nothing is ever hard-deleted — a correction is a reversing entry, so history stays intact.
  • Every write is stamped with the acting user and the time.
  • Anything above a set threshold needs a second approver, so the treasurer cannot approve their own large spend.
  • A transfer between two club accounts is one entry, not two, so it never double-counts as income.
  • Membership fees feed the ledger automatically from the fee records — no double entry.
